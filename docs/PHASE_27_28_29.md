# UniversalLive — Phases 27–29

## Phase 27 — Secure destination credentials
- Adds `stream_destination_secrets`.
- Stream keys are encrypted server-side with AES-256-GCM.
- The mobile app/API never receives the saved plaintext secret back.
- Endpoints:
  - `GET /api/v1/destinations/:destinationId/credential`
  - `PUT /api/v1/destinations/:destinationId/credential`
  - `DELETE /api/v1/destinations/:destinationId/credential`
- Configure `STREAM_SECRET_MASTER_KEY` only in backend `.env`.

## Phase 28 — Account + history polish
- `GET /api/v1/account/overview`
- `GET /api/v1/account/streams/:id`
- Profile summary, destination count, scene count, stream count and detailed metrics history.

## Phase 29 — Admin monitoring API
- Internal admin API protected by `x-admin-key`.
- `GET /api/v1/admin/overview`
- `GET /api/v1/admin/streams/live`
- `GET /api/v1/admin/streams/recent`
- `GET /api/v1/admin/streams/:id`
- `POST /api/v1/admin/streams/:id/mark-ended`
- Admin audit log foundation.

## SQL
Run `backend/supabase/migrations/0003_secure_credentials_admin.sql` after `0001` and `0002`.

## Backend env additions
```
STREAM_SECRET_MASTER_KEY=<long-random-server-only-secret>
ADMIN_API_KEY=<long-random-admin-key>
```
Do not put either value in the Android APK.
