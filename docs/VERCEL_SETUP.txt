UNIVERSAL LIVE — VERCEL BACKEND SETUP

1. Push the whole E:\UniversalLive repository to:
https://github.com/Mahimedia456/universallive

2. Vercel:
Add New Project
-> Import Git Repository
-> Mahimedia456/universallive

3. IMPORTANT:
Set Root Directory:
backend

Do not deploy Android/KMP root as the backend project.

4. Framework:
Other / No Framework
Vercel can detect src/server.ts as a Node server.

5. Node.js:
Use Node.js 24.x.

6. Add Vercel Environment Variables:

NODE_ENV=production
SUPABASE_URL=<same Supabase project URL>
SUPABASE_PUBLISHABLE_KEY=<sb_publishable_...>
SUPABASE_SECRET_KEY=<real sb_secret_...>
CORS_ORIGINS=*
STREAM_SECRET_MASTER_KEY=<NEW production secret>
ADMIN_API_KEY=<NEW production admin key>

Set these for Production.
You can also set them for Preview if preview deployments need to function.

DO NOT put PORT manually in Vercel.
Vercel provides it.

DO NOT commit backend/.env.

7. Deploy / Redeploy.

8. Expected production checks:

https://YOUR-VERCEL-DOMAIN.vercel.app/api/v1/health
https://YOUR-VERCEL-DOMAIN.vercel.app/api/v1/foundation
https://YOUR-VERCEL-DOMAIN.vercel.app/api/v1/security/status
https://YOUR-VERCEL-DOMAIN.vercel.app/api/v1/system/final-status
https://YOUR-VERCEL-DOMAIN.vercel.app/api/v1/billing/plans

9. After those URLs respond, use this as the mobile API base URL:

https://YOUR-VERCEL-DOMAIN.vercel.app/api/v1

The next mobile integration patch will wire:
- sign up/login/verification
- profile
- memberships
- channel connections
- Studio scenes/sources
- live session/telemetry/history
- notifications/support

Do not move to Admin before this mobile API integration is validated.
