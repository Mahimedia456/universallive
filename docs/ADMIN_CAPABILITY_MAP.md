# Admin Capability Map

| Domain | Admin surface | Priority | Reference |
|---|---|---:|---|
| Authentication / Admin access | Login, session, protected routes, roles | Critical | Backend auth/admin |
| Dashboard | KPIs, live operations, alerts, health | Critical | Streams + system state + analytics |
| Users | Directory + detail + account operations | Critical | Account/profiles |
| Creators | Creator directory/detail + operational state | Critical | Profiles + streams |
| Broadcasts | Live/scheduled/history/detail | Critical | Broadcast sessions + lifecycle + history |
| Connections | Streaming connections + destinations | Critical | Streaming connections/destinations |
| OAuth / RTMP | Integration state + diagnostics | Critical | Platform OAuth + RTMP credentials |
| Studio | Workspace/scenes/sources/overlays | High | Studio/scenes/source domains |
| Devices | Device inventory + status | High | Devices |
| Diagnostics | Technical failures + diagnostics | High | Diagnostics/telemetry |
| Billing | Plans/subscriptions/billing | High | Billing |
| Entitlements | Feature access | High | Entitlements |
| Notifications | Notification operations | High | Notifications |
| Support | Tickets + detail + operations | High | Support |
| Security | Audit/security events | Critical | Security audit |
| System | Service health + system state | Critical | System state |
| Admin settings | Profile/preferences/roles | Medium | Admin |
| Global search | Cross-domain discovery | Medium | Admin UX layer |
