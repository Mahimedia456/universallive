# Phase 09 - Home - LOCKED

Approved visual: `APPROVED_PHASE_09_HOME.png`

Home is the creator command center, not a social feed.

It contains:
- Ready / not-ready hero state
- Direct Go Live or Add Destination CTA
- Real saved destination state
- Current scene
- Current resolution/FPS/bitrate
- Permission-aware microphone readiness
- Quick actions for Connections, Studio, Audio and Stream Quality
- Recent backend notifications/activity
- Active-stream return banner when a live session is already running

No fake viewer/feed/community metrics are shown.
