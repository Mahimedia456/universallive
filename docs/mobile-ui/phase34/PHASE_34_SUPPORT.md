# Phase 34 — Support

Locked scope: support hub, streaming troubleshooting, backend-backed contact support, recent support tickets, and direct links to Connections / Diagnostics / Streaming Settings.

Rules:
- Never expose access tokens, passwords or stream keys in support UI.
- Ticket submission uses the existing backend support contract.
- Unsupported diagnostics attachments are not faked; diagnostics remain a separate review screen until the backend accepts diagnostic payloads.
